My Physio

My Physio es un ERP cuyo primer módulo es una red social que conecta pacientes y fisioterapeutas para enviar rutinas de ejercicios personalizadas para hacer en casa.

Tecnologías: desarrollado para Android con Android Studio y Kotlin, con base de datos Firebase. Participación: proyecto personal. Roles: diseño, desarrollo fullstack y testing.



Server socket chatbot

Server socket chatbot es un proyecto de la asignatura Programación de servicios y procesos de DAM. Consiste en un chat bot que comunica cliente y servidor a través de consola, cuyo fin es devolver una contraseña basada en los parámetros que se le pasan al servidor.

Tecnologías: desarrollado con Eclipse en Java. Participación: proyecto personal. Roles: diseño, desarrollo y testing.



Zoominoutron

Zoominoutron es un videojuego de plataformas con puzles desarrollado para PC hecho con Unity donde controlamos a Nikola, un niño prodigio de la ciencia que tras sufrir un accidente, adquiere la habilidad de hacerse grande o pequeño a voluntad. Deberemos usar este poder para escapar de la habitación en la que estamos encerrados tras el accidente para encontrar una cura.

Tecnologías: desarrollado con unity y Visual Studio en C#. Para las partidas guardadas se usa un Json local. Participación: proyecto personal. Roles: diseño, desarrollo fullstack y testing.



Unity Essentials Project

Unity Essentials Project es un proyecto modular que se realiza al seguir el curso de Unity Essentials de Unity,en el cual en cada lección desarrollas un módulo,los cuales juntas al final a través de un menú.

Tecnologías: desarrollado con Unity y Visual Studio en C#. Participación: proyecto personal. Roles: desarrollo fullstack.



Cube Clicker

Cube Clicker es un videojuego de Android con un cubo cuyas caras estás coloreadas,y clicando en ellas, impulsamos hacia arriba el cubo. Debemos evitar que el cubo caiga, con la dificultad añadida de que cada click, cambia el color de fondo con el mismo color de la cara clicada, y si clicamos en una cara del mismo color que el fondo el juego termina.

Tecnologías: desarrollado con Unity y Visual Studio con C#. Participación: proyecto personal. Roles: diseño, desarrollo y testing.
