Unity Essentials Project

Unity Essentials Project es un proyecto modular que se realiza al seguir el curso de Unity Essentials de Unity,en el cual en cada lección desarrollas un módulo,los cuales juntas al final a través de un menú.

Tecnologías: desarrollado con Unity y Visual Studio en C#. Participación: proyecto personal. Roles: desarrollo fullstack.
