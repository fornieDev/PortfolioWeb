Zoominoutron

Zoominoutron es un videojuego de plataformas con puzles desarrollado para PC hecho con Unity donde controlamos a Nikola, un niño prodigio de la ciencia que tras sufrir un accidente, adquiere la habilidad de hacerse grande o pequeño a voluntad. Deberemos usar este poder para escapar de la habitación en la que estamos encerrados tras el accidente para encontrar una cura.

Tecnologías: desarrollado con unity y Visual Studio en C#. Para las partidas guardadas se usa un Json local. Participación: proyecto personal. Roles: diseño, desarrollo fullstack y testing.
