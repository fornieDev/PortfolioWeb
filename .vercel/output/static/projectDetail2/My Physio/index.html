My Physio

My Physio es un ERP cuyo primer módulo es una red social que conecta pacientes y fisioterapeutas para enviar rutinas de ejercicios personalizadas para hacer en casa.

Tecnologías: desarrollado para Android con Android Studio y Kotlin, con base de datos Firebase. Participación: proyecto personal. Roles: diseño, desarrollo fullstack y testing.
